# MetroX

An offline, Google-free fork of [Retro Music Player](https://github.com/RetroMusicPlayer/RetroMusicPlayer), with the de-Google work from [Metro](https://github.com/MuntashirAkon/Metro) re-applied.

- No `INTERNET` permission.
- Last.fm, Deezer, online lyrics, Cast and Play services removed.
- Local playback only: themes, gapless/crossfade playback, now playing styles, widgets, tag editor, playlists, sleep timer, Android Auto.

## Build

Requires JDK 21.

```
./gradlew assembleRelease
```
